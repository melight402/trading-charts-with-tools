# Trading Charts with Tools

Библиотека расширений для Lightweight Charts с дополнительными инструментами для рисования и технического анализа.

## Описание

Библиотека предоставляет расширенные возможности для работы с графиками на основе Lightweight Charts:
- Дополнительные инструменты рисования
- Интеграция с TradingView-подобными инструментами
- Поддержка линий тренда, фигур и аннотаций

## Установка

```bash
npm install
```

## Использование

Библиотека используется как зависимость в других проектах:
- `tradingFront`
- `historyFront`

## Зависимости

- `fancy-canvas` - для работы с canvas

npm run lint
